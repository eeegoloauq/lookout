
## Install

| System | File |
|---|---|
| Linux, x86-64 | `lookout-linux-amd64` |
| Linux, ARM64 | `lookout-linux-arm64` |
| Docker | `ghcr.io/eeegoloauq/lookout` |

`SHA256SUMS` lists the checksum of every file. [Setup](https://github.com/eeegoloauq/lookout/blob/main/docs/setup.md) covers the config, systemd and updates.
